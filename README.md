# Fullstack TypeScript Template

Готовый шаблон (Template-репозиторий) для быстрого старта разработки fullstack-приложений с настроенной контейнеризацией.

## Архитектурная особенность
Проект полностью переведен на TypeScript 7. Это обеспечивает строгую типобезопасность, поддержку актуальных возможностей компилятора и максимальную скорость статического анализа кода как на фронтенде, так и на бэкенде.

## Суть проекта
Цель репозитория — минимизировать время на настройку окружения (boilerplate). Инфраструктура полностью готова к работе: фронтенд и бэкенд связаны типами, база данных инициализируется автоматически, а Docker-окружение поддерживает горячую перезагрузку (Hot Reload) для обоих приложений.

## Структура проекта

```text
.
├── backend/            # Серверное Express приложение (API)
├── frontend/           # Клиентское React приложение (Интерфейс)
├── database/           # Скрипты инициализации и миграций PostgreSQL
└── docker-compose.yml  # Конфигурация контейнеризации всего стека
```

## Быстрый старт

1. Создайте новый репозиторий на основе этого шаблона.
2. Клонируйте проект к себе на локальную машину.
3. Создайте файл `.env` в корневом каталоге и задайте необходимые переменные (примеры указаны ниже).
4. Запустите всю инфраструктуру одной командой:
   ```bash
   docker compose up --build
   ```
5. Откройте приложения в браузере:
   * Фронтенд: `http://localhost:5173`
   * Бэкенд API: `http://localhost:3001`

## Бэкенд (Backend)

Серверная часть приложения представляет собой жестко типизированный REST API.

### Стек технологий
* Node.js — среда выполнения (ES Modules).
* TypeScript 7 — строгая типизация и компиляция.
* Express — веб-фреймворк для API.
* PostgreSQL — основная база данных (драйвер pg).
* Zod — валидация входных данных и схем запросов.
* JWT и Bcrypt — безопасная авторизация и хеширование паролей.
* Morgan — логирование HTTP-запросов.

### Локальные команды
* `npm run dev` — запуск для разработки с автоперезапуском через tsx watch.
* `npm run build` — компиляция кода в JavaScript (папка dist).
* `npm run start` — запуск готового production-сервера из dist.

## Фронтенд (Frontend)

Клиентское веб-приложение с быстрым циклом сборки и компонентной архитектурой.

### Стек технологий
* React 19 — библиотека для создания интерфейсов.
* TypeScript 7 — строгая типизация компонентов и хуков.
* Vite — инструмент сборки и HMR (Hot Module Replacement).
* React Router 7 — декларативная маршрутизация страниц.
* ESLint — проверка качества, стандартов и стиля кода.

### Локальные команды
* `npm run dev` — запуск локального сервера разработки с флагом --host.
* `npm run build` — проверка типов с помощью tsc -b и сборка проекта для production.
* `npm run lint` — статический анализ кода на ошибки.
* `npm run preview` — локальный запуск и проверка собранного production-билда.

## Контейнеризация (Docker Compose)

Весь стек контейнеризирован и готов к запуску без необходимости локальной установки Node.js, PostgreSQL или инструментов сборки.

### Сервисы контейнеризации
* backend — Node.js сервер (порт 3001). Запускается в режиме разработки, код синхронизирован с хостом через volumes. Ожидает готовности БД перед стартом.
* frontend — React приложение (порт 5173). Поддерживает интерактивный режим (stdin_open).
* db — База данных PostgreSQL 14 (Alpine). Настроен Healthcheck (pg_isready) и автоматическое выполнение скриптов инициализации из папки ./database.

### Команды управления контейнерами
* `docker compose up --build` — сборка образов и запуск всех контейнеров.
* `docker compose down` — остановка и удаление запущенных контейнеров.
* `docker compose down -v` — полная остановка с очисткой сохраненных данных базы (volumes).

### Ключевые переменные окружения (.env)
* `VITE_API_URL` — адрес бэкенда для клиентской части (http://localhost:3001).
* `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` — параметры подключения к PostgreSQL.
* `JWT_SECRET` — секретный ключ для подписи токенов авторизации.
